# 日期范围确认、统一按钮与封面加载

2026-10-31，继 2b5a5d2 后修复站长实际访问时发现的问题。

- 复现：网页 HTML 更新后，浏览器仍可能使用缓存 12 小时的旧 app.js，导致新加的快捷范围没有事件处理。JS/CSS 现在使用内容哈希版本 URL，sync 每次自动计算，避免新旧混用；离线单文件仍内联资源。发布时先更新资源、最后更新 HTML。每日同步先暂存并校验 HTML/JS/CSS，版本不一致时保留整组线上文件；服务器常驻脚本的镜像和自定义设置保留。
- 过去所有、过去 1 年、自定义日期统一为先选择、点击确定后应用。恢复默认只更新当前草稿；Esc 或点外部取消草稿。没有选择时确定按钮真实禁用，已有快捷范围可以确认。
- 日历整套控件统一宋体文字、墨绿加粗和赭石下划线，移除渐变、圆角胶囊与按钮描边。保留纸色和纸纹。
- 封面只对已实施本地化的 kpopping 请求本站副本；Apple/网易云直接请求原图源，随心歌单也复用该规则。原来 5223 条发行全部先试本地，实际只有 101 张本地专辑封面，大量无效 404 在前面增加等待。
- 实测样本：无效本地请求耗时 2.38/2.69 秒；直接外部请求耗时 2.17/3.31 秒。这里只说明本次环境样本，图片最终速度仍受外部图源和访问线路影响。
