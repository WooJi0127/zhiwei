# 2026-10-20

## 修复：发行类型判错（NMIXX《Strange Muse》EP 被标成正规专）

**用户要求**：没有标明明确的就暂时不记录专辑类型，等数据更新时一起检查，有就补、没有就继续不记。

**真根因（比预想深）**：`step_retype()` 每轮用标题重判所有条目，把 kpopping 明确给的类型**冲掉**。
kpopping 日历 JSON 里本来直接写着 `Mini Album` / `Single` / `EP` / `Album` / `OST`，
但《Strange Muse》这种标题没关键词的，被旧逻辑默认成 Album —— 整批 kpopping 条目都被洗成「正规专」。

**改动（scripts/build.py）**：
- 新增 `rtype_src` 字段存源生类型（含老库 ALTER TABLE 迁移），永不覆盖
- 新增 `map_src_type()`：Single/Digital Single→Single，Mini/EP→EP，Album/Repackage/Compilation/Live→Album
- `step_retype()` 优先级：源生类型 → 标题线索 → 跨源对齐 → 留空
- `parse_subtype()` 删掉曲目数启发式，判不出来返回 `None`
- 跨源对齐 `_title_key()`：同专辑借别的源的类型，只有无分歧才借（如 "Go in Blind" 同时是 EP 和 Single 就放弃）
- 导出合并时改成「只有自己没类型才借」，不再覆盖已有类型

**改动（core/app.js）**：`catOf()` / `typeLabel()` 空类型返回 `""`，卡片和详情页不再渲染空的 `<span class="tag">`。

**效果**：主文件 990 张里 700 张有明确类型（原 584 张）。NMIXX《Strange Muse》→ EP ✓
