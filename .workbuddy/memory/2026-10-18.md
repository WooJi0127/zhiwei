## 迁移国内可行性咨询（用户提问：先打磨网站，再迁阿里云，是否可行）

结论：可行且推荐，但**顺序要改**——域名实名 + 备案是最长链路（10–20 天），不能等网站做完才启动。

### 核实到的硬事实（阿里云官方文档，2026-10）
- **不买服务器拿不到备案服务码**。可备案云产品 = ECS（包年包月 ≥3 个月 + 公网带宽）、轻量应用服务器、
  建站市场产品、函数计算套餐包（≥100 元/包月 3 月）、万小智 AI 建站等。免费试用 ECS 不算。
- **OSS 不在可备案云产品列表里**：OSS 绑自定义域名只要求该域名「已有工信部备案号」，
  但不强制接入阿里云 → OSS 本身不能用来申请服务码。
- 最省钱组合：**买一台最便宜的轻量应用服务器当「备案门票」（活动价约 ¥40–110/年），
  网站本体放 OSS + CDN**（1.3MB 静态站，流量费一年可能只要十几块）。
- 备案期间只是「域名不能解析到国内服务器」，海外（Cloudflare）站点照常可访问 → 网站不用停。

### 迁移成本核查结果
- `site/app` 仅 **1.3MB**（其中 `data/data.js` 1.2MB）纯静态 → 换托管＝把同一批文件传到别处。
- 硬编码域名检查：`core/`、`site/index.html` **无** workers.dev 硬编码；
  只有 `desktop/main.js`（Electron 远程数据备份源 `zhiwei-kpop.pages.dev`）有，不影响网页迁移。

### 盈利功能候选（本轮新增，用户问「有什么功能能盈利」）

**核心判断（已答复）**：日历本身不值钱——kpopping 免费提供同样内容，靠"看日期"收费不成立。
真正值钱的是两个时刻：**「你快错过的时候」（提醒）** 和 **「你正要掏钱的时候」（购买导流）**。

给出的功能排序（贴合度 × 实现成本）：
1. **专辑详情页「去购买」联盟链接** —— 用户此刻购买意图 100%，转化链路最短。
   平台候选：淘宝客（国内门槛低）、Amazon Associates（正式联盟）、YesAsia。
   Ktown4u / Weverse Shop 是否有公开联盟计划**未核实**，需用户自行确认。
   合规：页面需标注"含推广链接"。
2. **本命回归提醒推送**（邮件 / Telegram Bot）—— 唯一有订阅价值的功能。
   技术：Cloudflare Workers + Resend（免费 3000 封/月）。卡点：个人备案属非经营性，
   收费订阅理论需经营性 ICP 许可证（要公司主体）。
3. **年度追星报告**（粉丝年度报告）—— 不直接赚钱，但是唯一能带来爆发式分享流量的功能，
   参照网易云年度报告 / 支付宝年度账单。作用是给广告和赞赏喂流量。
4. **收藏 / 本命云同步** —— 应**免费**做，用来攒注册用户，收费会引发反感（README 已记载
   收藏存 localStorage、换设备会丢，是真实痛点）。
5. **打榜投票日程** —— K-pop 粉丝刚需且差异化，但数据需人工维护。

明确不做：卖数据 API（第三方数据版权）、演唱会票务（资质 + 黄牛风险）、周边自营电商。

## 商业化咨询（用户提问：怎么盈利维持运营）

给出的方案要点（已答复）：
- **成本侧**：当前托管在 Cloudflare Workers 免费额度内，真实开销只有域名（¥60-100/年）；
  160MB exe/apk 不要走 CDN 做网页流量，改 GitHub Releases 或对象存储下载加速，这是最大一笔隐形开销。
- **变现优先级**（由易到难）：①赞赏/爱发电 → ②联盟返利（专辑详情页加 Ktown4u/YesAsia/淘宝客购买外链）
  → ③AdSense 广告（需流量规模）→ ④会员增值（云端同步收藏/本命 + 回归提醒推送，¥3-5/月，需后端账号体系）。
- **不建议**：卖第三方 API 数据（kpopping/Apple Music 抓取，版权与条款风险）、自营电商（需资质+供应链）、
  使用艺人官方照/logo（商标风险在商业化后放大）。kpopcal 数据是 CC BY 4.0，可商用但需署名。
- **前提**：国内托管 + ICP 备案是后续变现（国内广告联盟、支付）的地基，与 WILLDO P1 一致。
- 建议在动手前先挂 Cloudflare Web Analytics（免费、免备案、无需 cookie 弹窗）摸清真实流量，
  因为所有变现路径的收益都由 DAU/PV 决定。

  整段空值保护。**凡是加在 document 级委托里的代码，一律先判空再操作。**
